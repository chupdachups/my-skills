# MCP 서버 초기화 질문

사용자에게 순서대로 다음 질문을 하세요.

## 1. 서버 이름

**질문**: MCP 서버의 이름을 입력해주세요.

**유효성 검사**:
- 영문 소문자만 허용
- 하이픈(-) 허용
- 숫자 허용 (첫 글자 제외)
- 공백 불가

**예시**: `weather-server`, `github-mcp`, `my-api-server`

---

## 2. 서버 설명

**질문**: 이 MCP 서버가 제공할 기능을 간단히 설명해주세요.

**가이드**:
- 한 문장으로 명확하게
- 주요 기능 포함

**예시**:
- "날씨 정보를 조회하고 예보를 제공하는 서버"
- "GitHub 저장소의 이슈와 PR을 관리하는 서버"

---

## 3. 프로그래밍 언어

**질문**: 어떤 프로그래밍 언어로 개발하시겠습니까?

**옵션**:
| 언어 | 설명 |
|------|------|
| `typescript` | Node.js 기반, 타입 안전성, npm 생태계 |
| `python` | 간결한 문법, 풍부한 라이브러리, ML/AI 친화적 |

---

## 4. 전송 방식

**질문**: 클라이언트와의 통신 방식을 선택해주세요.

**옵션**:
| 방식 | 설명 | 권장 사용 사례 |
|------|------|----------------|
| `stdio` | 표준 입출력 사용 | 로컬 실행, CLI 도구 |
| `sse` | Server-Sent Events | 웹 기반, 원격 서버 |

**기본값**: `stdio` (대부분의 경우 권장)

---

## 5. 제공할 기능

**질문**: 서버에서 제공할 기능을 선택해주세요. (복수 선택 가능)

**옵션**:
| 기능 | 설명 |
|------|------|
| `tools` | LLM이 호출할 수 있는 동작/함수 (예: API 호출, 파일 작업) |
| `resources` | LLM 컨텍스트에 로드할 데이터 (예: 문서, 설정) |
| `prompts` | 재사용 가능한 프롬프트 템플릿 |

**권장**: 최소 `tools` 또는 `resources` 하나 이상 선택
