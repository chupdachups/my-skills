# Brownfield Feature 초기화 질문 템플릿

## 기본 정보 수집

### 필수 질문

| 질문 | 옵션 | 목적 |
|------|------|------|
| 추가하려는 기능 설명 | 자유 입력 | 기능 범위 파악 |
| 설계 문서 유무 | 있음/없음 | 워크플로우 분기 |
| 프로젝트 숙지도 | 익숙함/분석필요 | 분석 스킬 필요성 |

### 선택 질문

| 질문 | 옵션 | 기본값 |
|------|------|--------|
| 우선순위 | 긴급/보통/낮음 | 보통 |
| 기존 코드 수정 | 가능/최소화 | 가능 |
| 테스트 요구사항 | 단위/통합/선택 | 선택 |
