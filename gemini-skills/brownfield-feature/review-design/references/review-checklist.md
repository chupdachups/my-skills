# 설계 문서 검토 체크리스트

## 1. 문서 완전성 검토

### 요구사항 섹션
- [ ] 기능 요구사항이 명확하게 정의되어 있는가?
- [ ] 비기능 요구사항이 측정 가능한 기준으로 정의되어 있는가?
- [ ] 사용자 스토리 또는 유스케이스가 있는가?
- [ ] 예외 케이스가 고려되어 있는가?
- [ ] 범위(In/Out of Scope)가 명시되어 있는가?

### 기술 설계 섹션
- [ ] 아키텍처 개요가 있는가?
- [ ] 컴포넌트/모듈 설계가 있는가?
- [ ] 데이터 모델이 정의되어 있는가?
- [ ] API 설계가 있는가? (해당시)
- [ ] 상태 관리 방식이 정의되어 있는가?
- [ ] 에러 처리 방식이 정의되어 있는가?

### 영향 분석 섹션
- [ ] 새로 생성할 파일 목록이 있는가?
- [ ] 수정할 파일 목록이 있는가?
- [ ] 영향받는 기존 기능이 식별되어 있는가?
- [ ] 의존성 변경이 명시되어 있는가?

### 기타 섹션
- [ ] 테스트 계획이 있는가?
- [ ] 위험 및 완화 방안이 있는가?
- [ ] 마이그레이션 계획이 있는가? (필요시)
