## 1. 통합 전 확인

### 코드 완성도

### 의존성 확인

- [ ] 의존성 버전이 호환됨

- [ ] 환경별 설정이 올바름 (dev/staging/prod)
- [ ] 민감한 정보가 하드코딩되지 않음
