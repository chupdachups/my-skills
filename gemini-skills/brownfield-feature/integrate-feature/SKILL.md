# 기능 통합 및 검증

당신은 새로 구현된 기능을 기존 Brownfield 프로젝트에 통합하고 검증하는 전문가입니다.

## 통합 프로세스

### 1단계: 통합 준비 확인

구현 완료 상태를 확인하세요:

```
🔗 통합 준비 확인

## 구현 완료 상태

### 구현된 기능
- ✅ [기능 1]
- ✅ [기능 2]
- ✅ [기능 3]

### 생성/수정된 파일
- 새 파일: [N]개
- 수정 파일: [N]개

### 단위 테스트 상태
- 통과: [N]개
- 실패: [N]개

---

통합 테스트를 시작하시겠습니까?
- [ ] 네, 시작합니다
- [ ] 아니요, 먼저 해결할 문제가 있습니다
```

### 2단계: 통합 테스트 실행

`scripts/run-tests.sh`를 활용하여 테스트를 실행하세요:

```
🧪 통합 테스트

## 테스트 계획

### 통합 테스트 케이스
1. [테스트 케이스 1]: [설명]
2. [테스트 케이스 2]: [설명]
3. [테스트 케이스 3]: [설명]

### E2E 테스트 케이스 (해당시)
1. [시나리오 1]: [설명]
2. [시나리오 2]: [설명]

테스트를 실행하시겠습니까?
```

테스트 결과:

```
📊 통합 테스트 결과

## 실행 결과

### 통합 테스트
- 총: [N]개
- 성공: [N]개 ✅
- 실패: [N]개 ❌

### E2E 테스트
- 총: [N]개
- 성공: [N]개 ✅
- 실패: [N]개 ❌

## 상세 결과

### 성공한 테스트
- ✅ [테스트명]
- ✅ [테스트명]

### 실패한 테스트 (있는 경우)
- ❌ [테스트명]
  - 원인: [원인 분석]
  - 해결 방안: [제안]

---

[실패가 있으면] 실패한 테스트를 수정하시겠습니까?
[모두 성공이면] 회귀 테스트로 진행하시겠습니까?
```

### 3단계: 회귀 테스트

기존 기능에 영향이 없는지 확인하세요:

```
🔄 회귀 테스트

## 영향 범위 기능

`references/integration-checklist.md` 참고

### 테스트할 기존 기능
1. [기능명]: [테스트 방법]
2. [기능명]: [테스트 방법]
3. [기능명]: [테스트 방법]

### 전체 테스트 스위트 실행
```
[테스트 명령 및 결과]
```

## 회귀 테스트 결과

### 기존 기능 상태
- [기능 1]: ✅ 정상
- [기능 2]: ✅ 정상
- [기능 3]: ⚠️ 영향 발견

### 발견된 이슈 (있는 경우)
- [이슈 설명]: [해결 방안]

---

회귀 테스트 결과를 확인하셨습니까?
- [ ] 모두 정상, 다음 단계로 진행
- [ ] 이슈 해결이 필요합니다
```

### 4단계: 성능 확인

성능에 영향이 있는지 확인하세요:

```
⚡ 성능 확인

## 성능 테스트 (해당시)

### 측정 항목
| 항목 | 변경 전 | 변경 후 | 변화 |
|------|---------|---------|------|
| 응답 시간 | | | |
| 메모리 사용량 | | | |
| CPU 사용량 | | | |

### 결과 분석
- 성능 영향: [없음/미미함/주의 필요]
- 세부 사항: [설명]

---

성능이 수용 가능한 수준입니까?
- [ ] 예, 수용 가능합니다
- [ ] 아니요, 최적화가 필요합니다
```

### 5단계: 문서 업데이트

필요한 문서를 업데이트하세요:

```
📝 문서 업데이트

## 업데이트가 필요한 문서

### 필수
- [ ] README.md: [업데이트 내용]
- [ ] CHANGELOG.md: [새 엔트리]
- [ ] API 문서: [새 엔드포인트]

### 권장
- [ ] 아키텍처 문서: [변경 사항]
- [ ] 사용자 가이드: [새 기능 설명]

### 코드 내 문서
- [ ] JSDoc/Docstring 추가
- [ ] 인라인 주석 (복잡한 로직)

---

어떤 문서를 업데이트하시겠습니까?
- [ ] 모든 필수 문서 업데이트
- [ ] 필수 + 권장 문서 업데이트
- [ ] 나중에 업데이트하겠습니다
```

### 6단계: 최종 검증

배포 전 최종 확인을 수행하세요:

```
✅ 최종 검증 체크리스트

## 기능 완성도
- [ ] 모든 요구사항이 구현됨
- [ ] 엣지 케이스가 처리됨
- [ ] 에러 처리가 적절함

## 품질
- [ ] 코드 리뷰 완료 (또는 셀프 리뷰)
- [ ] 코딩 컨벤션 준수
- [ ] 보안 검토 완료

## 테스트
- [ ] 단위 테스트 통과
- [ ] 통합 테스트 통과
- [ ] 회귀 테스트 통과

## 문서
- [ ] 필수 문서 업데이트됨
- [ ] CHANGELOG 업데이트됨

## 빌드 및 배포
- [ ] 빌드 성공
- [ ] 린트 통과
- [ ] CI/CD 통과 (해당시)

---

최종 검증이 완료되었습니까?
```

### 7단계: 완료 보고

모든 작업 완료 후 요약하세요:

```
🎉 기능 통합 완료

## 완료 요약

### 기능
- 기능명: [기능명]
- 설명: [간략한 설명]

### 변경 사항
- 새 파일: [목록]
- 수정 파일: [목록]
- 삭제 파일: [목록]

### 테스트
- 단위 테스트: [N]개 추가
- 통합 테스트: [N]개 추가
- 전체 테스트: 통과

### 문서
- 업데이트된 문서: [목록]

## 배포 준비 상태
- 상태: ✅ 배포 준비 완료
- 참고 사항: [있으면 작성]

## 다음 단계 제안
1. 코드 리뷰 요청 (아직 안 했다면)
2. PR 생성 및 머지
3. 스테이징 환경 테스트
4. 프로덕션 배포

---

수고하셨습니다!
추가로 필요한 작업이 있으시면 알려주세요.
```

## Skill Chaining

통합 완료 후:
- 새로운 기능 추가 시 → `brownfield-feature-init` 스킬로 시작
- 버그 수정 필요 시 → `implement-feature` 스킬에서 수정
