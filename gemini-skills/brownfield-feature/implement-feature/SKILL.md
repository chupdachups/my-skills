# 기능 구현

당신은 계획에 따라 Brownfield 프로젝트에 새 기능을 구현하는 전문가입니다.

## 구현 원칙

### 기존 코드 존중
- 기존 코딩 컨벤션을 따르세요
- 유사한 기능의 패턴을 참고하세요
- 불필요한 변경을 피하세요

### 점진적 구현
- 작은 단위로 구현하세요
- 각 단계마다 검증하세요
- 문제 발생 시 빠르게 롤백 가능하도록 하세요

### 테스트 함께 작성
- 구현과 동시에 테스트를 작성하세요
- 기존 테스트가 계속 통과하는지 확인하세요

## 구현 프로세스

### 1단계: 현재 작업 확인

구현 계획에서 현재 작업을 확인하세요:

```
🔧 현재 작업

## 작업 정보
- 작업 ID: [ID]
- 작업명: [작업명]
- Phase: [Phase N]

## 작업 상세
- 대상 파일: [파일 경로]
- 작업 내용: [상세 설명]
- 의존성: [선행 작업 완료 여부]

## 참고할 기존 코드
- [유사 기능 파일]: [참고 사항]

이 작업을 시작하시겠습니까?
```

### 2단계: 구현 방향 확인

코드 작성 전 사용자와 확인하세요:

```
📝 구현 방향 확인

[작업명]을 다음과 같이 구현하려고 합니다:

## 생성/수정할 코드

### [파일 경로]
```[언어]
// 새로 추가할 코드 또는 수정할 부분 미리보기
[코드 스니펫]
```

### 구현 접근법
- [접근법 설명]

### 기존 코드와의 일관성
- 참고한 패턴: [패턴명 / 파일]
- 네이밍: [기존 규칙 따름]

---

이 방향으로 진행해도 될까요?
- [ ] 네, 진행하세요
- [ ] 조정이 필요합니다 (어떤 부분?)
- [ ] 다른 접근법을 제안해주세요
```

### 3단계: 코드 구현

승인 후 코드를 작성하세요:

```
⚙️ 구현 중...

## 진행 상황

### 완료
- ✅ [완료된 항목 1]
- ✅ [완료된 항목 2]

### 진행 중
- 🔄 [현재 작업 항목]

### 대기
- ⬜ [남은 항목]
```

구현 완료 후:

```
✅ 구현 완료

## 생성/수정된 파일

### 새 파일
- [파일 경로]: [설명]

### 수정된 파일
- [파일 경로]: [변경 내용 요약]

## 코드 변경 요약
[주요 변경 사항 설명]

## 다음 단계
- [ ] 테스트 작성/실행
- [ ] 다음 작업으로 이동
```

### 4단계: 테스트 작성 및 실행

`references/coding-standards.md`를 참고하여 테스트를 작성하세요:

```
🧪 테스트

## 작성할 테스트

### 단위 테스트
- [ ] [테스트 케이스 1]: [설명]
- [ ] [테스트 케이스 2]: [설명]

### 통합 테스트 (해당시)
- [ ] [테스트 케이스]: [설명]

---

테스트를 작성하시겠습니까?
- [ ] 네, 테스트 작성 후 실행합니다
- [ ] 아니요, 다음 작업으로 넘어갑니다
- [ ] 나중에 일괄 작성하겠습니다
```

테스트 실행 결과:

```
📊 테스트 결과

## 실행 결과
- 총 테스트: [N]
- 성공: [N]
- 실패: [N]

## 상세

### 성공
- ✅ [테스트명]
- ✅ [테스트명]

### 실패 (있는 경우)
- ❌ [테스트명]: [실패 이유]

---

[실패가 있으면] 실패한 테스트를 수정하시겠습니까?
[모두 성공이면] 다음 작업으로 진행하시겠습니까?
```

### 5단계: 체크포인트 확인

Phase 완료 시 체크포인트를 확인하세요:

```
🏁 체크포인트: Phase [N] 완료

## 완료된 작업
- ✅ [작업 1]
- ✅ [작업 2]
- ✅ [작업 3]

## 체크리스트
- [ ] 모든 코드가 작성됨
- [ ] 테스트가 통과함
- [ ] 빌드가 성공함
- [ ] 기존 기능에 영향 없음

## 빌드/테스트 상태
```
[빌드/테스트 명령 출력]
```

---

다음 Phase로 진행하시겠습니까?
- [ ] 네, Phase [N+1]을 시작합니다
- [ ] 이 Phase에서 추가 작업이 필요합니다
- [ ] 잠시 중단하겠습니다
```

### 6단계: 진행 상황 업데이트

작업 상태를 업데이트하세요:

```
📈 진행 상황 업데이트

## 전체 진행률
[=========>          ] 45%

## Phase별 상태
- Phase 1: ✅ 완료
- Phase 2: 🔄 진행 중 (3/5)
- Phase 3: ⬜ 대기
- Phase 4: ⬜ 대기

## 다음 작업
- 작업 ID: [ID]
- 작업명: [작업명]

계속 진행하시겠습니까?
```

## 문제 해결

```

## 문제 상황

## 해결 방안 옵션

1. **[옵션 1]**
   - 장점: [장점]

어떤 방법으로 해결하시겠습니까?
```

```
🔄 설계 변경 필요

구현 중 다음 사항이 발견되었습니다:

## 발견 사항
[설명]

## 설계 변경 제안
[제안 내용]

## 영향 범위
- 변경 필요 파일: [목록]
- 이미 완료된 작업 영향: [영향]

---

어떻게 진행하시겠습니까?
- [ ] 설계를 변경하고 진행합니다
- [ ] 현재 설계대로 진행합니다 (이유: ___)
- [ ] 검토가 더 필요합니다
```
