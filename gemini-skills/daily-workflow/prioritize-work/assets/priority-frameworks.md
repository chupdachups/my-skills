# 우선순위 결정 프레임워크

## 1. 아이젠하워 매트릭스

### 개요
드와이트 아이젠하워 대통령이 사용한 의사결정 프레임워크

### 4분면

| 분면 | 긴급 | 중요 | 행동 |
|------|------|------|------|
| 1 | ✅ | ✅ | DO NOW - 즉시 실행 |
| 2 | ❌ | ✅ | SCHEDULE - 일정 잡기 |
| 3 | ✅ | ❌ | DELEGATE - 위임하기 |
| 4 | ❌ | ❌ | DELETE - 제거하기 |

### 판단 기준

**긴급한가?**
- 마감이 오늘/내일인가?
- 즉시 대응이 필요한가?
- 지연 시 큰 문제가 발생하는가?

**중요한가?**
- 목표 달성에 기여하는가?
- 장기적 가치가 있는가?
- 나만 할 수 있는 일인가?

## 2. MIT (Most Important Tasks)

### 개요
하루 중 가장 중요한 1-3개 작업에 집중

### 규칙
1. 매일 아침 3개 이하의 MIT 선정
2. 다른 일 전에 MIT 먼저 완료
3. MIT 완료 = 성공적인 하루

### MIT 선정 질문
- "오늘 이것만 해도 만족스러운 하루일까?"
- "이걸 미루면 가장 큰 문제가 될까?"
- "나의 가장 큰 목표에 기여하는가?"

## 3. ABCDE 방법

### 분류
- **A**: 반드시 해야 함 (심각한 결과)
- **B**: 해야 함 (가벼운 결과)
- **C**: 하면 좋음 (결과 없음)
- **D**: 위임 가능
- **E**: 제거 가능

### 규칙
- A 작업을 모두 완료하기 전에 B 시작 금지
- A가 여러 개면 A1, A2, A3로 세분화

## 4. 파레토 법칙 (80/20)

### 개요
20%의 작업이 80%의 결과를 만든다

### 적용
1. 모든 할일 나열
2. 각 작업의 잠재적 영향력 평가
3. 상위 20% 작업 식별
4. 그 작업에 우선 집중

### 질문
- "이 작업이 가져올 결과의 크기는?"
- "어떤 작업이 가장 큰 레버리지를 가지는가?"

## 5. 시간-에너지 매트릭스

### 개요
작업에 필요한 시간과 에너지를 기준으로 분류

```
        고에너지 필요    저에너지 OK
       ┌────────────┬────────────┐
긴 시간 │  딥워크     │  루틴 작업  │
필요    │  (아침)     │  (오후)    │
       ├────────────┼────────────┤
짧은    │  스프린트   │  틈새 작업  │
시간    │  (집중 시)  │  (언제든)  │
       └────────────┴────────────┘
```

## 6. 먹는 개구리 (Eat the Frog)

### 개요
가장 어렵고 중요한 일을 아침 첫 번째로

### 원칙
> "아침에 살아있는 개구리를 먹으면, 그날 남은 시간은 그보다 나쁜 일이 없다"

### 적용
1. 전날 밤 또는 아침에 "개구리" 식별
2. 아침 가장 먼저 그 작업 수행
3. 완료 후 나머지 작업 진행

## 7. Warren Buffett의 25-5 규칙

### 방법
1. 원하는 것 25개 나열
2. 상위 5개 선택
3. 나머지 20개는 "절대 하지 않을 목록"으로

### 핵심
- 좋은 것도 포기해야 최고에 집중 가능
- "아니오"라고 말하는 용기

## 실전 적용 가이드

### 아침 루틴 (5-10분)
1. 어제 미완료 작업 확인
2. 오늘 할일 브레인덤프
3. MIT 3개 선정
4. 첫 작업 시작

### 주간 리뷰 (30분)
1. 완료 작업 확인
2. 미완료 작업 재분류
3. 다음 주 주요 목표 설정
4. 2사분면(중요+긴급X) 작업 일정 배정

### 우선순위 재조정 시점
- 새로운 긴급 작업 발생 시
- 예상보다 오래 걸리는 작업 발생 시
- 에너지 레벨 변화 시
- 외부 상황 변경 시
