# 할일 분류 가이드

## GTD (Getting Things Done) 기반 분류

### 1. 수집 (Capture)
모든 할일을 머릿속에서 꺼내 한 곳에 모으기

### 2. 명확히 하기 (Clarify)
각 항목에 대해 질문:
- 이게 뭔가? 행동이 필요한가?
- 2분 안에 할 수 있나?
- 내가 해야 하나? 위임할 수 있나?
- 언제까지 해야 하나?

### 3. 정리하기 (Organize)
분류 체계에 따라 배치

### 4. 검토하기 (Reflect)
정기적으로 목록 검토

### 5. 실행하기 (Engage)
상황에 맞는 할일 선택 후 실행

## 시간 기반 분류

| 분류 | 기한 | 특성 |
|------|------|------|
| 🔥 Today | 오늘 | 반드시 오늘 완료 |
| 📅 This Week | 이번 주 | 주 내 완료 필요 |
| 📆 This Month | 이번 달 | 월 내 완료 |
| 🗓️ Someday | 미정 | 언젠가 하고 싶은 것 |

## 에너지 기반 분류

| 레벨 | 아이콘 | 설명 | 적합한 작업 |
|------|--------|------|-------------|
| High | 🔋🔋🔋 | 높은 집중력 필요 | 복잡한 문제 해결, 창의적 작업 |
| Medium | 🔋🔋 | 보통 집중력 | 일반 업무, 미팅 |
| Low | 🔋 | 낮은 에너지 OK | 정리, 이메일, 간단한 작업 |

## 우선순위 분류

### 아이젠하워 매트릭스

```
          긴급함        긴급하지 않음
        ┌────────────┬────────────┐
중요함   │ 1. DO      │ 2. DECIDE  │
        │ 즉시 실행   │ 일정 잡기   │
        ├────────────┼────────────┤
중요하지 │ 3. DELEGATE│ 4. DELETE  │
않음     │ 위임       │ 삭제       │
        └────────────┴────────────┘
```

### MoSCoW 방법

| 분류 | 의미 | 설명 |
|------|------|------|
| Must | 반드시 | 필수, 없으면 안됨 |
| Should | 해야 함 | 중요하지만 필수는 아님 |
| Could | 할 수 있음 | 있으면 좋음 |
| Won't | 안 함 | 이번에는 하지 않음 |

## 프로젝트 분해 가이드

### 좋은 할일의 특징
- ✅ 동사로 시작 (명확한 행동)
- ✅ 구체적 (모호하지 않음)
- ✅ 측정 가능 (완료 여부 명확)
- ✅ 한 번에 처리 가능 (너무 크지 않음)

### 예시

❌ 나쁜 예: "프로젝트 진행하기"
✅ 좋은 예: "프로젝트 요구사항 문서 초안 작성하기"

❌ 나쁜 예: "운동하기"
✅ 좋은 예: "오후 6시에 30분 러닝하기"

## 2분 규칙 체크리스트

2분 이내로 할 수 있는 일 예시:
- [ ] 이메일 빠른 답장
- [ ] 짧은 메시지 보내기
- [ ] 간단한 예약하기
- [ ] 파일 정리하기
- [ ] 간단한 결정 내리기
- [ ] 메모 작성하기
