# 집중 기법 가이드

## 1. 포모도로 테크닉

### 기본 구조
- 25분 집중 + 5분 휴식 = 1 포모도로
- 4 포모도로 후 15-30분 긴 휴식

### 규칙
1. 타이머가 울리기 전에는 멈추지 않기
2. 방해가 오면 "나중에"라고 기록하고 계속
3. 25분 완료 = 1 포모도로 획득
4. 중단된 포모도로는 카운트 안 함

### 변형
- **짧은 포모도로**: 15분 + 3분 (집중력 훈련 초기)
- **긴 포모도로**: 45분 + 15분 (익숙해진 후)

## 2. 타임박싱

### 개념
작업에 정해진 시간 박스를 할당하고 그 안에서만 작업

### 방법
1. 작업 선택
2. 시간 할당 (30분, 1시간 등)
3. 타이머 설정
4. 시간 내 최대한 진행
5. 시간 종료 시 무조건 중단

### 장점
- 파킨슨 법칙 방지 (일이 주어진 시간만큼 늘어나는 현상)
- 완벽주의 방지
- 추정 능력 향상

## 3. 딥워크 (Deep Work)

### 개념
방해 없이 인지적으로 요구되는 작업에 몰입하는 상태

### 조건
- 최소 50-90분 연속 시간
- 모든 방해 요소 제거
- 단일 작업에만 집중
- 명확한 목표 설정

### 4가지 딥워크 철학

| 철학 | 설명 | 예시 |
|------|------|------|
| 수도승 | 완전히 고립 | 오두막에서 집필 |
| 이중 | 주기적 딥워크 기간 | 1주일 작업 + 1주일 일반 |
| 리듬 | 매일 같은 시간 | 매일 오전 6-9시 |
| 저널리스트 | 틈날 때마다 | 빈 시간 활용 |

## 4. 울트라디안 리듬

### 개념
90분 주기의 인간 생체 리듬에 맞춘 작업

### 구조
- 90분 집중 + 20분 휴식
- 하루 4-5 사이클 가능

### 과학적 근거
- 인간의 주의력은 90분 주기로 변동
- 수면 사이클과 동일한 리듬

## 5. 플로우 상태 (Flow State)

### 진입 조건
1. **명확한 목표**: 무엇을 할지 명확히
2. **즉각적 피드백**: 진행 상황 확인 가능
3. **적절한 도전**: 너무 쉽지도 어렵지도 않게
4. **통제감**: 작업을 제어하고 있다는 느낌
5. **방해 제거**: 외부 자극 차단

### 플로우 방해 요소
- 멀티태스킹
- 알림
- 불명확한 목표
- 너무 쉽거나 어려운 작업

## 6. 집중력 회복 기법

### 5-4-3-2-1 그라운딩
1. 5가지 보이는 것 확인
2. 4가지 들리는 것 확인
3. 3가지 만질 수 있는 것 확인
4. 2가지 냄새 맡기
5. 1가지 맛 느끼기

### 박스 호흡
- 4초 들이쉬기
- 4초 멈추기
- 4초 내쉬기
- 4초 멈추기
- 4회 반복

### 2분 리셋
- 자리에서 일어나기
- 스트레칭
- 물 마시기
- 창밖 보기
- 다시 앉기

## 7. 방해 요소 관리

### 디지털 방해
| 방해 요소 | 해결책 |
|-----------|--------|
| 휴대폰 | 다른 방에 두기, DND 모드 |
| 이메일 | 특정 시간만 확인 |
| 메신저 | 상태 메시지로 알리기 |
| SNS | 앱 삭제 또는 차단 |

### 환경 방해
| 방해 요소 | 해결책 |
|-----------|--------|
| 소음 | 노이즈 캔슬링, 백색 소음 |
| 동료/가족 | 집중 시간 공유, 표시 |
| 어수선함 | 작업 전 정리 |

### 내적 방해
| 방해 요소 | 해결책 |
|-----------|--------|
| 다른 생각 | 캡처 리스트에 기록 |
| 불안 | 5분 명상, 호흡 |
| 피로 | 짧은 낮잠, 휴식 |
